# Cómo trabajar conmigo

- Respuestas cortas. Sin resúmenes de lo que acabas de hacer salvo que lo pida.
- Cuando cambies código, enséñame solo lo que cambia, no el archivo entero.
- Lee solo los archivos que necesites. Si te doy una ruta, empieza por ahí y no explores el resto del proyecto.
- Nunca vuelques salidas enormes (logs, JSON grandes, builds). Filtra con grep, head, tail o jq.
- Ejecuta solo los tests relacionados con el cambio, no la suite completa, salvo que lo pida.
- No lances subagentes ni tareas en paralelo salvo que lo pida.
- Si la tarea es ambigua, pregúntame una vez antes de empezar en vez de probar varias opciones.
- Para tareas grandes, dame primero un plan de 5 líneas como máximo y espera mi OK.
